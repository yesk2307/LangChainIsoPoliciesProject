# LangChain ISO Policies Project

A Python project for processing and interacting with ISO policy documents.

## Setup

### 1. Activate the Virtual Environment

```bash
source .venv/bin/activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Copy `.env.example` to `.env` (already done) and configure any necessary API keys.

```bash
cp .env.example .env
```

## Running the Application

```bash
python main.py
```
